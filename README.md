## DEPENDENCIES.bat
This file has been created to help users install all of the required python modules in order for the main python script to work.
Here's what it does:
 - The script utilises the Python binary as well as PIP directly to ensure that most Python installations can install the packages.
```
python.exe -m pip install XYZ
```
```
pip.exe install XYZ
```
